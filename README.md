# Дедлайнер

## Как добавлять задания через файл

Откройте файл `tasks.js` и добавьте объект внутрь массива `window.initialTasks`:

```js
window.initialTasks = [
  {
    id: 1,
    subject: "Математика",
    title: "Параграф 12, номера 4-6",
    dueDate: "2026-09-05",
    note: "Учебник, стр. 48",
    done: false
  }
];
```

Дата записывается в формате `год-месяц-день`. После изменения откройте `index.html`, чтобы проверить результат, затем загрузите файлы в GitHub Pages.

Задания, добавленные через форму, сохраняются только в браузере через `localStorage`.
